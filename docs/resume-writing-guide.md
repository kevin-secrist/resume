# Resume Writing Guide

## MEDIC Framework

Quantify impact using metrics:

- **M**aintained - uptime, reliability, stability (e.g., "Maintained 99.9%+ uptime")
- **E**liminated - bottlenecks, manual processes, technical debt (e.g., "Eliminated manual deployment process")
- **D**ecreased - costs, time, errors, latency (e.g., "Decreased build time by 50%")
- **I**ncreased - efficiency, scale, quality, revenue (e.g., "Increased throughput 10x")
- **C**reated - new systems, processes, frameworks (e.g., "Created automated testing framework")

When exact numbers unavailable, use approximations: ~ or +/- to indicate scale.

## ATS Optimization

**Formatting:**
- Standard fonts: Arial, Calibri, Helvetica (10-12pt body, 14-16pt headers)
- Avoid tables, columns, graphics, text boxes
- Standard section headers: "Professional Experience", "Education", "Technical Skills"
- Consistent date format: Month Year - Month Year

**Keywords:**
- Include both acronyms AND full terms on first mention (e.g., "AWS (Amazon Web Services)")
- Extract keywords from target job descriptions
- List technologies in multiple contexts (skills section + experience bullets)
- Target 75%+ keyword match with job postings

**Parsed Fields:**
- Job titles and company names
- Dates of employment
- Technical skills and tools
- Degree names and institutions
- Certifications

## Bullet Writing

**X-Y-Z Formula:**
"Accomplished [X] as measured by [Y], by doing [Z]"

- X = Impact (what you achieved)
- Y = Metric (how you measured it)
- Z = Method (how you did it)

**Example:**
"Reduced deployment time by 75% (from 2 hours to 30 minutes) by implementing automated CI/CD pipeline with GitHub Actions and Docker layer caching"

**Impact-First:**
Lead with outcome, not task.

- Weak: "Responsible for monitoring production systems"
- Strong: "Maintained 99.9%+ uptime across 16+ critical applications serving thousands of customers"

**Action Verbs:**
- Leadership: Led, architected, established, mentored, guided
- Technical: Implemented, developed, built, designed, optimized
- Impact: Reduced, increased, eliminated, improved, accelerated
- Ownership: Maintained, owned, operated, managed, supported

## Section Ordering

**Recommended order:**

1. **Professional Summary** (3-5 sentences)
   - Years of experience + specialization
   - Key technical areas
   - Highest-impact metrics
   - Current role level

2. **Technical Skills/Expertise**
   - Organized by category (Languages, Frameworks, Platforms)
   - Bold primary technologies
   - Include tools and practices

3. **Professional Experience**
   - Reverse chronological
   - 3-6 bullets per role
   - Focus on impact and metrics
   - Include technologies used

4. **Projects**
   - Side projects demonstrating skills
   - Open source contributions
   - Technical depth beyond day job

5. **Education**
   - Degree, institution, graduation date
   - Relevant coursework (recent grads only)
   - GPA if appropriate

**Exclude:**
- "Objective" statements
- "References available upon request"
- Unrelated work history (unless early career)
- Personal hobbies unrelated to role
- Soft skills without evidence ("team player", "hard worker")

**Length:**
- 0-5 years: 1 page
- 5-10 years: 1-2 pages
- 10+ years: 2 pages maximum
